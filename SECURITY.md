## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability or potential security flaw, please do **NOT** open a public issue or report it publicly.

### Disclosure Process

1. **Private Notification**: Please report all security vulnerabilities directly via email to `security@yourdomain.com`.
2. **Details to Include**:
   * Description of the vulnerability and its potential impact.
   * Step-by-step instructions or proof-of-concept (PoC) to reproduce the issue.
   * Any suggested remediations or patches if available.
3. **Response Time**: You will receive an initial acknowledgment of your report within 48 hours. We aim to assess and validate reports within 5 business days.
4. **Coordinated Disclosure**: We ask that you give us reasonable time to investigate and address the vulnerability before making any public disclosure.

Thank you for helping keep our project and users secure!
